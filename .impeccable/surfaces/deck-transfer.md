# Deck transfer

Mode: Operate. Extend the existing deck builder and local deck editor.
User intent: move a deck recipe into Master Duel, and import an exported game recipe back. User confirms KONAMI ID is linked and official My Deck is accessible. User finds the extension workflow too complicated. Desktop now opens an isolated built-in official browser, reuses its valid login session, creates a blank recipe and fills it; official Save and game Copy remain explicit user actions. Web mode retains the extension fallback.

## Direction contract
THESIS: Put the game transfer beside existing exports; make desktop transfer one action with login in the official window and short save/copy steps, with no claim that a text export alone imports into the game.
OWN-WORLD: Preserve the current charcoal panels, restrained blue action, existing system type and button vocabulary. Add inline panels with sequential instructions rather than a modal or a separate product shell.
STORY: Select a recipe, check MD compatibility, sign in once in the built-in official browser, open a blank official editor with the recipe filled, save and copy in game. The reverse path accepts YDK files or YDKE codes into a new local deck.
FIRST VIEWPORT: The transfer action sits with builder exports and local editor actions. Its revealed panel shows the deck name and counts, the main built-in action, collapsed backup exports, and final game instructions. Import reveals a labeled text/file input and a preview before saving.
FORM: Narrow local extension of the established surface; no concept seed or new visual world.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
