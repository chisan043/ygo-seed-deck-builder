# AI API settings extension

Mode: Operate. Existing workbench visual identity is fixed; scope is an AI settings tab following Banlist, a connection form, and an editable prompt form; per-build preferences are merged into the builder search panel and shown only in AI model mode.

## Direction contract

THESIS: Players configure their own model and ask for a coherent deck without leaving the existing builder.
OWN-WORLD: Preserve the charcoal panels, blue action/focus colors, sharp input corners and existing button families. No new imagery or page identity.
STORY: Open AI settings, configure endpoint/model/key, optionally edit and independently save the prompt, then return to the builder and generate with optional play-style requirements. Sample mode returns public recipes only; model mode requires configured API settings and reports failures without algorithm substitution.
FIRST VIEWPORT: The AI settings tab follows Banlist in the top navigation. Its first panel contains three labeled connection fields, retention guidance and save/test/clear actions. Its second panel shows the actual editable system prompt, independent save/reset controls and readable appended output rules. Per-build preferences and cancel status share the builder search panel; sample mode hides the preferences, and model mode shows them. Desktop uses a three-column connection form; narrow widths stack it.
FORM: Local extension of the established builder; no concept tournament or generated comp applies. Existing inputs and deck panels are incumbent visual authority.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

No raster assets added. Existing DESIGN.md is absent, and PRODUCT.md Register metadata is pre-existing drift; this extension does not repair it. Requests use user-configured OpenAI-compatible Chat Completions. Legacy heuristic recipes remain readable, but neither selected mode silently substitutes them. The reverted native game-transfer feature stays removed.
