# Single builder input

This shipped refinement follows `.impeccable/surfaces/ai-settings.md` and the incumbent workbench. It combines card/theme search and model requirements into exactly one `#cardInput`. The charcoal panels, green actions and mode selection, blue navigation, existing focus treatment, and deck workspace remain the visual authority. This is a narrow, code-led local refinement; no concept tournament, generated comp, or new product asset applies.

The field keeps a visible label and changes its label and example with the selected mode. Real samples accepts a card name or theme. AI model builds accepts a complete sentence, such as “围绕耀圣，优先后攻，少带手坑。” Players should place their primary card or theme first, followed by preferences and additional series. Chinese, Japanese, and English provide corresponding guidance.

The first recognized card/theme mention anchors the deck. The complete submitted sentence is passed explicitly as that request’s requirements through both card and theme routes. Theme results retain the original sentence in the field, allowing revision without reconstructing the request. When no topic is recognized, an actionable message asks the player to add a card or theme. This recognition uses known card/theme names; it does not claim general natural-language understanding.

Sample mode continues to show public recipes without model calls. Model mode continues to require configured settings and reports setup, cancellation, and provider errors without substituting sample or heuristic recipes. API-key retention, independently saved prompts, and settings storage are unchanged.
